# 산출물 위치 규약

## 세 위치의 역할

| 위치 | 의미 | 예 |
| --- | --- | --- |
| `docs/` | 여러 작업에서 다시 읽는 오래 사는 기준 | 정책, 템플릿, 프롬프트, 체크리스트 |
| `notes/` | 현재 요청과 실행 과정에 묶인 작업 기록 | 요청 정리, plan, diff 검토, handoff |
| `.github/` | GitHub가 읽고 동작시키는 플랫폼 설정 | Issue template, PR template |

판단이 애매하면 다음 질문을 사용합니다.

- 다음 작업에서도 기준으로 읽을 문서인가? 그러면 `docs/`입니다.
- 이번 작업의 판단과 실행 흔적인가? 그러면 `notes/`입니다.
- GitHub 화면이나 workflow가 직접 소비하는가? 그러면 `.github/`입니다.

## 폴더 최초 생성 시점

| 폴더 또는 파일 | 최초 생성 강 | 그전 상태 |
| --- | --- | --- |
| `notes/` | 2강 | 존재하지 않음 |
| `AGENTS.md` | 4강 | 존재하지 않음 |
| `docs/` | 6강 | 존재하지 않음 |
| `.github/` | 8강 | 존재하지 않음 |
| `notes/plans/` | 12강 | 존재하지 않음 |

최초 생성 시점보다 앞선 lab에서 해당 위치를 미리 만들지 않습니다. 특히 공개 시작 상태에 `.github/`를 두지 않습니다.

## 파일명 규칙

- 커리큘럼에 경로가 지정된 파일은 이름을 바꾸지 않습니다.
- 보조 작업 기록은 `<topic>-lNN.md` 형식을 우선합니다.
- 같은 내용을 `docs/`와 `notes/` 양쪽에 복제하지 않습니다.
- 교재 입력은 `labs/fixtures/` 또는 해당 강의 `inputs/`에 둡니다.

## 변경 규칙

- `labs/`는 모든 체크포인트에서 같은 내용을 유지합니다.
- 학생 산출물이나 완성 코드를 `labs/` 아래에 두지 않습니다.
- 4강에 만드는 root `AGENTS.md`의 `Before Editing`에서 이 문서를 참조합니다.
