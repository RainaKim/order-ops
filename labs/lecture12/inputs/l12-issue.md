# 결제 성공 이후에만 재고 반영

## Summary

주문 생성 시 재고가 줄고 재고보다 많은 주문도 생성되는 현재 동작을 정책과 맞춥니다. 결제에 실패한 주문은 사라지지 않아야 합니다.

## Current Behavior

- 주문 생성 직후 상품 재고가 감소합니다.
- 재고보다 많은 수량도 주문할 수 있습니다.
- 실패 결제 뒤 주문을 조회할 수 없습니다.

## Acceptance Criteria

- [ ] 재고가 부족한 주문은 저장되기 전에 거절됩니다.
- [ ] 주문 생성만으로 재고가 감소하지 않습니다.
- [ ] 성공 결제 뒤에만 주문 수량만큼 재고가 감소합니다.
- [ ] 결제 실패 주문과 시도 기록이 보존됩니다.
- [ ] test, lint, typecheck가 통과합니다.

## Out of Scope

- 관리자 표시 상태 계산 교정
- 외부 결제사 연동
- 데이터베이스 도입
